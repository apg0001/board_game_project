# 게임 규칙 준수 감사표

이 문서는 각 게임 모듈이 "플레이 가능한 프로토타입"인지 "공식/표준 규칙 기반 구현"인지 숨기지 않고 추적하기 위한 기준표다.

## 판정 기준

- [ ] 시작 세팅, 구성물 수량, 인원별 배분이 규칙과 일치한다.
- [ ] 턴 순서와 필수/선택 행동이 규칙과 일치한다.
- [ ] 공개/비공개 정보가 플레이어별로 안전하게 분리된다.
- [ ] 종료 조건과 승패/점수 계산이 규칙과 일치한다.
- [ ] 잘못된 행동은 서버에서 거절되고 테스트로 검증된다.
- [ ] 모바일 UI가 현재 가능한 행동만 보여준다.
