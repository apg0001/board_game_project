# 우선순위 로드맵

작업 추적용 체크리스트는 [우선순위 체크리스트](checklist.md)를 기준으로 관리한다.

## 우선순위 기준

1. 친구들과 실제로 접속해 같은 방에 모일 수 있는가
2. 모바일에서 끊김 없이 플레이 흐름이 이어지는가
3. 게임을 하나씩 추가해도 코어가 흔들리지 않는가
4. 테스트로 회귀를 빠르게 잡을 수 있는가

## P0 기반 완료

### P0-1 PWA 프론트 하네스

상태: 완료

- React/Vite

### P0-2 Go 백엔드 하네스

- `.env.example` 기반 로컬/LAN 실행 가이드

## P1 바로 플레이 가능한 로비

목표: PC 한 대와 모바일 여러 대가 같은 방에 들어와 Ready까지 할 수 있다.

### P1-0 Quick Match

상태: 완료

- Quick Match API
- 대기 방 큐
- 프론트 퀵매치 버튼 연결

### P1-A 자체 회원 인증

상태: MVP 완료

- ID/Password 회원가입
- 로그인
- 세션 토큰
- 프론트 계정 패널

### P1-1 게스트 세션

상태: 완료

작업 브랜치:

```txt
feature/#3-guest-session
```

작업:

- `internal/guest` 패키지 추가
- 게스트 ID/닉네임 생성
- 인메모리 저장소
- `POST /api/guests`
- `GET /api/me`
- 프론트 자동 게스트 생성

검증:

- Go 단위 테스트
- HTTP 테스트
- 새로고침 후 게스트 유지

### P1-2 방 생성/입장

상태: API/UI 완료, 실시간 동기화는 P1-3에서 진행

작업 브랜치:

```txt
feature/#4-room-lobby
```

작업:

- `internal/room` 패키지 추가
- 방 코드 생성
- 방 생성 API
- 방 코드 입장 API
- 방 조회 API
- 참가자 목록 UI

검증:

- 방 코드 중복 방지 테스트
- 방 입장 인원 제한 테스트
- PC/모바일 동시 접속 수동 테스트

### P1-3 WebSocket 방 동기화

상태: 다음 작업

작업 브랜치:

```txt
feature/#5-room-realtime
```

작업:

- room 채널 join
- 참가자 입장/퇴장 브로드캐스트
- Ready 토글 브로드캐스트
- 방장 위임

검증:

- WebSocket 통합 테스트
- 두 브라우저에서 Ready 상태 동기화
